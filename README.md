## 一、研究背景

人工智能正在从科研的辅助工具转变为科学发现过程的参与者。近十年，AI 方法在数学猜想与符号推理、材料与分子设计、蛋白质结构预测、方程发现、自主实验等方向持续产出标志性成果；与此同时，主要国家的科技政策也先后把 AI 驱动的科学研究列为重点方向，"AI for Science" 由此成为科研组织和科技政策的重要议题。

但 AI4S 至今没有统一、可操作的边界。研究文献中，"仅在背景提及 AI""把常规数值优化或自动微分当作 AI 参与"与"AI 实质承担了预测、设计、发现或实验任务"混杂在一起；跨学科检索又会带入大量相邻领域的非目标文献。因此，**样本能否被逐篇复核、检索与筛查过程能否被重建**，直接决定了基于该样本得出的趋势判断是否可信。

本项目即以 2010—2026 年 Web of Science 核心合集文献为对象，考察 AI 实质参与数学、自然科学与工程科学问题求解的**演进路径与科研介入方式**，采用文献计量与重点文献内容分析相结合的方法。本仓库是这项研究的"数据底账"：检索式、原始导出、逐篇筛查依据与每一次版本变更全部留痕。

## 二、项目数据集的用途

### 2.1 数据概况

当前 v3 以 **9,470 篇核心样本**支撑计量分析，另以 **10,189 条全量审计**记录每一篇文献的去留依据。

| 分类        | 数量         | 说明          |
| --------- | ----------:| ----------- |
| 核心样本      | 9,470      | 当前分析使用的样本   |
| 拓展参考      | 534        | 补充阅读，不计入核心  |
| 待正文补证     | 20         | 关键证据仍缺，暂不纳入 |
| 非目标或非原创排除 | 161        | 保留排除理由      |
| 重复或撤稿旧版移除 | 4          | 保留出版关系与处置记录 |
| **审计合计**  | **10,189** | 各类互斥        |

**范围与口径**

- 时间：2010—2026 年；2010—2025 年用于完整年度比较，2026 年为不完整年度，单列处理。
- 数据库：Web of Science 核心合集；文献类型 `Article`，语言 `English`。CNKI 数据另行整理与分析，不在本仓库内。
- 检索：三条互补路径——① 显式 AI4S 表述；② AI 方法 × 科研任务 × 科学领域；③ Scientific Machine Learning × 方程或物理约束。全局限制为 `PY=(2010-2026) AND LA=(English) AND DT=(Article)`。
- 筛选口径：以"AI 是否实际承担目标科研任务"为核心判据；纯观点、仅在背景提及 AI、常规数值优化或自动微分本身不作纳入证据。

### 2.2 可以做什么

1. **文献计量与知识图谱。** 核心样本的 19 个 WoS TXT 可直接导入 VOSviewer、CiteSpace 或 bibliometrix，用于年度产出、关键词共现、学科与期刊分布、机构与国家合作等分析。
2. **主题演化与介入方式研究。** 在计量结果基础上，对重点文献做内容分析，区分 AI 在科研中的角色（预测、生成、发现、设计、实验执行等）及其时间变化。
3. **检索策略复用与扩展。** 三条逻辑块、领域词表与 A/B/C 词项来源分级均可直接复用；也可用于其他数据库的检索式改造（如 CNKI、Scopus）。
4. **方法学与可复现性研究。** 筛查标准、证据层级、版本链和逐篇台账，可作为"如何构建可复核文献数据集"的示例。
5. **结果核验与二次研究。** 全量审计表保留每篇文献的原始记录与处置理由，任何人都能复核某一篇为何被纳入或排除。

### 2.3 使用前须知

- 做计量分析时以 `02_核心样本_9470篇.csv` 为准；分类判断请读取 `v3最终分类` 列，原模型分类列仅为历史记录。
- 两套 WoS TXT（"分析归年"与"来源 PY 保留"）记录相同，**只能择一导入**，不可叠加。
- "完成检索复核"不等于"完成全文终审"：原 8,247 篇沿用模型辅助筛选，1,412 篇复核与 51 篇补证的层级见逐篇台账。
- 付费全文或网页访问失败不作为排除理由，相关文献留在"待正文补证"。

## 三、仓库包含的内容

### 3.1 目录结构

```text
AI4S-database/
├── README.md                  # 本页：研究背景、数据集用途与仓库结构
├── search_terms.md            # 锁定检索式 V3.1-R3：逻辑块、字段、领域词、来源分级
├── search_results.md          # 从 11,637 条导出到 v3 的完整形成过程与修改历史
├── data/
│   └── packages/              # 数据包索引、下载入口、SHA256 与 Release 核验清单
├── docs/
│   └── DATA_GUIDE.md          # 资料位置、保留与精简建议
```

大文件统一存放在 Release，仓库内只保留索引、说明与小型台账，避免同一份数据在多个位置重复上传。

### 3.3 数据是如何形成的

```text
11,637 条原始导出
   │  前期筛除与撤稿移除 1,322 条
   ▼
10,315 条 → 领域筛除 126 条 → 10,189 条进入分区审计（累计移出 1,448 条）
   │
   ├─ v1（2026-10-21）：模型辅助筛选 → 核心 8,247 篇
   ├─ v2（2026-10-22）：复核 1,412 篇并合并 → 核心 9,446 篇
   └─ v3（2026-10-22）：51 篇补证（24 纳入 / 6 排除 / 1 转拓展 / 20 待证）→ 核心 9,470 篇
```

每一步的输入、操作与输出均可回溯，详见 [完整筛查历史](search_results.md) 与对应的 `reviews/` 阶段目录。
